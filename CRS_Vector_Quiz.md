
# Quiz - CRS + Vector Data

## 🧭 Coordinate reference systems

A ___CRS___ is a system used to represent locations on Earth as coordinates.

The Earth is best modeled as: An ellipsoid

False: All datums are global — the same one can be used for any region without loss of accuracy.

Name one key difference between a geographic CRS and a projected CRS.

    Projected CRS are 2D, geographic CRS are 3D.

The main purpose of a projection is to: Convert a 3D surface into a 2D map

False: Every projection perfectly preserves area, distance, and angles.

A projected CRS expresses coordinates in linear units such as ___km___.
